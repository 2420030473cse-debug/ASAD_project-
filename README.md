# Lane Detection and Lane Departure Warning System

## An Optimized Hybrid Computer Vision Approach for Advanced Driver Assistance Systems (ADAS)

### Abstract
Advanced Driver Assistance Systems (ADAS) are designed to improve road safety and reduce accidents caused by driver distraction and loss of lane control. Lane Detection and Lane Departure Warning (LDW) is an important ADAS function that identifies lane boundaries and warns the driver when the vehicle moves away from its lane. However, lane detection can become difficult because of curved roads, shadows, poor lighting, faded lane markings, and road noise.

This project proposes a lightweight hybrid computer vision approach for lane detection and lane departure warning. The proposed system uses Canny Edge Detection, Region of Interest (ROI), Perspective Transformation, Hough Transform, RANSAC, Polynomial Lane Fitting, and Temporal Smoothing to detect and track lane boundaries. The lane center is then estimated and compared with the vehicle position to identify possible lane departure. When the vehicle crosses a predefined safety threshold, a warning is generated.

The system will be developed and tested using publicly available lane detection datasets such as TuSimple and CULane. Performance will be evaluated using lane detection accuracy, lane departure detection accuracy, processing time, FPS, and false warning rate. The proposed approach aims to provide a simple, efficient, and computationally lightweight solution suitable for an academic ADAS prototype.
